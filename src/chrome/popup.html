Open local .md files (1-time setup)

Chrome blocks extensions on file:// pages until you allow it once:

  1. Open chrome://extensions
  2. Click Details on docmap
  3. Turn on Allow access to file URLs

Works automatically on

  • github.com README & Markdown pages
  • raw.githubusercontent.com & Gist raw .md
  • Local .md / .markdown files (after setup above)
