# Preview in the same tab

Open any `.md` file and press **Ctrl+Alt+V** (Mac: **Cmd+Alt+V**). The tab becomes a page with a clickable outline.
Press it again to edit.

**Always open `.md` files as a preview:** right-click any Markdown tab → **Reopen Editor With…** → **Configure default editor for `*.md`…** → **All-in-One Markdown Viewer (preview)**.
