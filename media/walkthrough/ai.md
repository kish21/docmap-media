# Your own AI — never ours

- **Default:** docmap writes the prompt and copies it — paste it into your agent (Claude Code, Codex, Copilot, Cursor…).
- **Answer With My Model** (setting, off): your model in VS Code answers on a page.
- **AI: Tools** (setting, off): your agents can ask docmap for plans, open questions, decisions, doc search, outlines and broken code paths — in Copilot or via `npx -y docmap-mcp` (`--install-skill` adds `SKILL.md`).
